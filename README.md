## Fonctionnalités
user : 
- register
- login + logout
- consulter le profil
- modifier le profil
- supprimer le compte

Annonce :
- Créer une annonce (Titre, description, prix, date d'ajout, catégorie)
- Consulter ses annonces
- Modifier ses annonces
- Supprimer ses annonces
- Voir les annonces de tout les utilisateurs
- "Acheter" une annonce

Recherche :
- Rechercher par titre
- Trier par catégorie, date d'ajout et prix

Message :
- Envoyer un message à un autre membre à propos d'une annonce spécifique
